void Watchdog_Init ( void )

Inicializa a supervisão.

Lê os registradores de backup (código da última falha e contador de reinícios), incrementa o contador se o último reset foi do IWDG e inicia os prazos de todas as tarefas. Chamar depois de MX_RTC_Init().

◆ Watchdog_Service()

void Watchdog_Service ( void )

Verifica os prazos e, se todas as tarefas estão em dia, realimenta o IWDG.

Marca a defaultTask como viva, atualiza wdg_stale_mask e realimenta o IWDG quando nenhuma tarefa está atrasada e já passaram pelo menos 100 ms desde a última realimentação. Deve ser chamada pela defaultTask e também dentro de operações longas (exportação e limpeza).
