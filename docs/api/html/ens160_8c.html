Descrição detalhada

Implementação do driver do ENS160 (ver ens160.h).

O driver é uma máquina de estados enxuta: detecta o sensor, só o coloca em modo padrão se ele não estiver medindo, espera dado novo e, após ciclos seguidos sem dado, reinicializa com RESET.

◆ ENS160_Read()

HAL_StatusTypeDef ENS160_Read ( bool compensation_valid,
float temperature_c,
float humidity_pct,
ENS160_Sample * out )

Lê uma amostra de qualidade do ar.

Detecta o sensor (confirmando o PART_ID), coloca-o em modo padrão se não estiver medindo, envia a compensação de temperatura e umidade, aguarda dado novo (cedendo a CPU) e lê AQI, TVOC e eCO2. Leituras com os três valores nulos não são medições e retornam HAL_BUSY. Após falhas seguidas, a próxima inicialização usa RESET.

Parâmetros
[in]compensation_validSe verdadeiro, envia temperature_c e humidity_pct ao sensor.
[in]temperature_cTemperatura de compensação, em °C (limitada a -40 a 85).
[in]humidity_pctUmidade de compensação, em % (limitada a 0 a 100).
[out]outAmostra lida.
Valores Retornados
HAL_OKAmostra válida.
HAL_BUSYO sensor ainda não produziu dado válido.
HAL_ERRORout nulo, sensor não encontrado ou erro interno do sensor.
Retorna
Outro status da HAL em caso de falha de comunicação I²C.
