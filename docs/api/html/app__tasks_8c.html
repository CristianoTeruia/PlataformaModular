Descrição detalhada

Código de aplicação do FreeRTOS: tarefas, mutexes, recuperação dos barramentos I²C e DIAG.

Fica FORA do main.c de propósito: o STM32CubeMX regenera o main.c e apaga tudo que estiver fora dos blocos USER CODE. Este arquivo não é tocado pela regeneração.

Tarefas (CMSIS-RTOS2):

  • defaultTask (prioridade normal): USB, RTC, exportação, limpeza e alimentação do watchdog;
  • sensorTask (abaixo do normal, pilha de 2048 B): aquisição e gravação a cada 10 s;
  • oledTask (baixa, pilha de 1536 B): atualização do display e botão.

Mutexes: EEPROM (serializa gravação, exportação e limpeza), I²C2 (OLED e EEPROMs), dados dos sensores e RTC.

void App_RTC_Lock ( void )

Obtém o mutex que protege o acesso ao RTC interno (leitura e ajuste) entre tarefas.

É um mutex "folha": nunca é mantido enquanto se espera por outro, portanto não cria deadlock. Não faz nada antes do início do RTOS.

HAL_StatusTypeDef RecoverI2C2AndOled ( void )
static

Recupera o I²C2 (OLED e EEPROMs) e reinicializa o SSD1306.

Obtém o mutex do I²C2 durante todo o processo. Libera uma linha possivelmente presa por um escravo (até 9 pulsos de SCL e uma condição de STOP, com os pinos como saída aberta), reinicia o periférico (HAL_I2C_Init faz o SWRST) e executa SSD1306_Init(). Atualiza i2c2_recovery_count e i2c2_recovery_status.

Retorna
Status da reinicialização do periférico ou do display.

◆ StartOledTask()

void StartOledTask ( void * argument)

Tarefa do display (prioridade baixa, ciclo de 20 ms).

Aplica a política de energia do OLED (OledPower), alterna as telas a cada 3 s, copia o estado compartilhado sob mutexes curtos e só então renderiza. Após uma atualização com falha, recupera o I²C2 e o SSD1306, no máximo uma vez a cada 5 s. Não retorna.

◆ StartSensorTask()

void StartSensorTask ( void * argument)

Tarefa de aquisição de sensores (prioridade abaixo da normal).

A cada SENSOR_ACQUISITION_INTERVAL_MS lê todos os sensores da tabela, grava um registro na EEPROM se pelo menos um respondeu e alterna o LED. Espera até 250 ms pelo mutex da EEPROM; se não o obtiver, a amostra é descartada. Após 3 ciclos seguidos sem nenhum sensor, tenta recuperar o I²C1, no máximo uma vez a cada 30 s. Não retorna.

Parâmetros
[in]argumentNão utilizado.
