◆ UpdateDisplaySnapshot()

void UpdateDisplaySnapshot ( const DisplaySnapshot * snapshot)

Desenha uma das duas telas e a envia ao display.

A tela 0 mostra o estado geral (OK, AVISO ou ERRO), os sensores saudáveis sobre os esperados, a validade do RTC e a primeira causa de erro. A tela 1 mostra a EEPROM ativa, o próximo endereço, o estado da USB e a linha de estágios de diagnóstico. Os sensores esperados são os já detectados desde o boot: um módulo não conectado não é erro, e sim um sensor que parou de responder.

Parâmetros
[in]snapshotEstado a exibir; ignorado se for nulo ou se o display não estiver disponível.
