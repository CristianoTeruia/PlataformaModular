Descrição detalhada

Registro de tamanho fixo do formato original (legado).

Foi substituído pelo registro de tamanho variável montado por EEPROM_BuildSensorRecord() e permanece apenas nas rotinas de teste manual. Os campos usam inteiros escalados.
