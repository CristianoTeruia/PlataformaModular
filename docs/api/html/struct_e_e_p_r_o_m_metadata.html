Descrição detalhada

Metadados da EEPROM, gravados a partir do endereço 0x0000 da EEPROM 1.

Indicam onde gravar o próximo registro. Só são considerados válidos se magic for igual a EEPROM_METADATA_MAGIC; metadados inválidos nunca são reinicializados sozinhos, para não perder registros.
