◆ App_Delay()

void App_Delay ( uint32_t ms)

Espera ms milissegundos cedendo a CPU quando o RTOS está em execução.

Usa osDelay com o kernel em execução e HAL_Delay antes dele. Evita que uma espera ocupada em tarefa de prioridade maior deixe as demais sem executar.

Parâmetros
[in]msTempo de espera, em milissegundos.
