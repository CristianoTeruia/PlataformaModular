Definições e macros

◆ ENABLE_IDLE_WFI

#define ENABLE_IDLE_WFI   1

Faz a tarefa ociosa do FreeRTOS dormir com a instrução WFI (1) ou não (0).

Reduz o consumo, pois o núcleo espera a próxima interrupção em vez de executar o laço ocioso. Use 0 ao depurar com breakpoints, porque o sono do núcleo pode interferir com alguns depuradores.

◆ ENABLE_WDT_TEST

#define ENABLE_WDT_TEST   0

Habilita (1) ou não (0) o comando USB WDTTEST.

O comando trava de propósito a sensorTask para demonstrar a atuação do watchdog. Mantenha 0 na versão de uso normal.

◆ OLED_AUTO_OFF_MS

#define OLED_AUTO_OFF_MS   30000U

Tempo sem atividade, em milissegundos, após o qual o OLED é apagado.

O botão (PA0) ou o início de uma operação USB acendem o display novamente. O valor 0 desativa o desligamento automático (display sempre aceso).
