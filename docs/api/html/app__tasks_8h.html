◆ App_RTOS_Create()

void App_RTOS_Create ( void )

Cria os mutexes e as tarefas adicionais da aplicação.

Cria quatro mutexes (EEPROM, I²C2, dados de sensores e RTC) e as tarefas sensorTask e oledTask. A defaultTask é criada pelo código gerado do CubeMX e executa App_CommandTask(). Deve ser chamada antes de osKernelStart() (bloco USER CODE de threads do main.c); chama Error_Handler() se alguma criação falhar.

void StartOledTask ( void * argument)

Tarefa do display (prioridade baixa, ciclo de 20 ms).

Aplica a política de energia do OLED (OledPower), alterna as telas a cada 3 s, copia o estado compartilhado sob mutexes curtos e só então renderiza. Após uma atualização com falha, recupera o I²C2 e o SSD1306, no máximo uma vez a cada 5 s. Não retorna.

◆ StartSensorTask()

void StartSensorTask ( void * argument)

Tarefa de aquisição de sensores (prioridade abaixo da normal).

A cada SENSOR_ACQUISITION_INTERVAL_MS lê todos os sensores da tabela, grava um registro na EEPROM se pelo menos um respondeu e alterna o LED. Espera até 250 ms pelo mutex da EEPROM; se não o obtiver, a amostra é descartada. Após 3 ciclos seguidos sem nenhum sensor, tenta recuperar o I²C1, no máximo uma vez a cada 30 s. Não retorna.

Parâmetros
[in]argumentNão utilizado.
