Descrição detalhada

Tipos, constantes e variáveis globais compartilhadas entre os módulos do firmware.

Reúne o mapa da EEPROM, os bits de identificação dos sensores, o intervalo de aquisição e as variáveis de estado e de diagnóstico lidas por mais de um módulo (definidas em app_state.c, app_tasks.c e freertos.c). Os campos volatile são escritos por uma tarefa e lidos por outra, por exemplo pelo comando USB DIAG.

◆ App_RTC_Lock()

void App_RTC_Lock ( void )

Obtém o mutex que protege o acesso ao RTC interno (leitura e ajuste) entre tarefas.

É um mutex "folha": nunca é mantido enquanto se espera por outro, portanto não cria deadlock. Não faz nada antes do início do RTOS.

◆ Diag_FaultBlink()

void Diag_FaultBlink ( uint8_t blinks)

Para o sistema por falha fatal, piscando o LED (PC13) em um padrão de diagnóstico.

Padrões: 2 piscadas = estouro de pilha de uma tarefa; 3 = falha de alocação no heap do FreeRTOS; 4 = HardFault. Grava 0xFA00 | blinks em BKP DR2 (lido no boot) e, como ninguém alimenta o IWDG, a placa reinicia sozinha de 11 s a 31 s depois. Não retorna.

Parâmetros
[in]blinksNúmero de piscadas do padrão.
