Descrição detalhada

Registro de sensores: tabela que descreve cada sensor I²C do sistema.

Cada sensor declara UMA entrada na tabela de sensor_registry.c: bit da máscara, tamanho do dado no registro, função de leitura, serialização e formatação em CSV. O restante do firmware (registro da EEPROM, exportação CSV, tarefa de sensores e OLED) apenas percorre a tabela. Adicionar um sensor equivale a escrever um driver e acrescentar uma linha na tabela.

Formato do registro gravado na EEPROM:

[máscara 1 B][dados dos sensores presentes, na ordem da tabela][RTC 7 B][CRC-16 2 B]

O RTC ocupa 7 bytes (ano em 2 bytes little-endian, mês, dia, hora, minuto e segundo) e o CRC é o CRC-16/CCITT-FALSE dos bytes anteriores, gravado em little-endian.

◆ Sensors_ReadOne()

void Sensors_ReadOne ( uint8_t index)

Lê um sensor e atualiza as máscaras "disponível agora" e "detectado desde o boot".

Se a leitura falha, o bit sai da máscara de disponíveis. HAL_BUSY (sensor responde, mas ainda não entrega dado) conta como detectado, para o OLED mostrar ERRO:<nome> em vez de ignorar um módulo conectado.

Parâmetros
[in]indexPosição do sensor na tabela (índices inválidos são ignorados).
