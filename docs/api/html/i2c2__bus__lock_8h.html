HAL_StatusTypeDef I2C2_BusAcquire ( void )

Obtém o mutex do barramento I²C2.

Antes do escalonador, as inicializações são sequenciais e a função retorna HAL_OK sem usar o mutex.

Valores Retornados
HAL_OKBarramento obtido (ou RTOS ainda não iniciado).
HAL_ERRORMutex inexistente ou falha ao obtê-lo.
